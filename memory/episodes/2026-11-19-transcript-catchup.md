### A2. Ciena Vesta 200／O-Net 溯源（用户 10:20Z 要求溯源；10:24–10:26Z 结论）——本窗主增量
用户原句：「Ciena's Vesta 200 demo runs on an 8-channel O-Net laser source — the ELS category Sivers supplies into」。

结论：**前半句已坐实：Ciena 官方明确说，Vesta 200 演示使用八通道 O-Net 外置光源。后半句应写成“Sivers 与 O-Net 有明确的激光阵列集成合作”，还不能说这台机器里就是 Sivers。**

证据链：
1. [Ciena 官方视频约 1:08](https://www.youtube.com/watch?v=ekM8i950CFg&t=68s) 公开字幕原话：“In this setup, we have an external laser source from O-Net, with eight channels, which delivers optical power to Vesta 200 optical engine.” 讲解者是 Ciena 系统架构师 Thai Son Le，地点是**新泽西实验室**，不是展会现场。视频页面发布于 11/13，拍摄日期未知。核对的是官方字幕与说明，**未观看视频画面**。
2. [2025/4/1 Sivers 公告](https://www.sivers-semiconductors.com/press/sivers-semiconductors-announces-strategic-oem-partnership-with-o-net-technologies-to-deliver-next-generation-external-laser-sources-for-co-packaged-optics/)：O-Net 将把 **Sivers 的 DFB 激光阵列集成进 ELSFP 外置光源模块**。未点名 Ciena，也未披露量产供货数量。
3. [2026/3/17 联合公告](https://www.newsfilecorp.com/release/288080/Sivers-Semiconductors-ONet-and-Enablence-Technologies-Announce-Collaboration-on-CoPackaged-Optics)：Sivers／O-Net／Enablence **八通道 ELS 共同开发**（Sivers 激光阵列，Enablence NxN 星形耦合器，O-Net 模块集成）。仍未把该模块与 Ciena 演示对应起来。
4. [O-Net 2022 年](http://www.o-netcom.com/m/news_view.aspx?Fid=t2%3A5%3A2&Id=609&TypeId=5&typefid=5) 已公开过八路、每路 20dBm（100mW）的 ELSFP。该规格不是 Sivers 独有指纹。Ciena 字幕只确认品牌和八通道，**没说型号、功率或波长**。模块输出功率也不能直接等同芯片功率（有耦合损耗）；八通道模块不必然等于一颗八通道单片阵列。

判断：这是有实质合作支撑的供应链线索，不是凭空联想；缺的关键一环，是这台 O-Net 光源**内部的激光来源**。即使确认演示用了 Sivers，也还要再区分演示样品、量产认证和生产订单。

建议改写，避免 “supplies into” 被读成已确认量产供货：

> Ciena’s Vesta 200 demo uses an eight-channel O-Net external laser source. Sivers and O-Net have announced laser-array integration work, including an eight-channel ELS collaboration with Enablence. The laser supplier inside Ciena’s demo unit, however, has not been disclosed.

用户说「目前都没有明确披露，作为投资者只能发现隐含关联」。助手补投资读法：不是等所有事确定，而是判断线索是否足以提高概率、以及股价有没有反映。Sivers／O-Net 有明确合作，2026 年又推进八通道 ELS，随后 Ciena 确认采用 O-Net 八通道光源——**足以把“Sivers 可能参与其中”列为值得认真对待的情景，而不是因为没点名就按零处理**；还不能给出可靠概率。允许进入判断，但别让仓位承担“已经确定”的风险；确认则提高权重，出现反证则下调。 〔引用：SIVE Watch 2026-11-18 A2；上述官方视频与公告 URL〕

Blazar 机制：把功率和波长拆开。波长由硅光中介层上的反射器和加热器调谐，功率来自供应商称良率较高的简单增益芯片和放大器，再在晶圆级放到中介层上。良率跟硅走，而不是跟磷化铟走；磷化铟部件更简单，可以来自多家供应商，扩产长在 POET 的组装线和硅晶圆厂，而不是新建一座激光芯片厂。官方引语：一颗 **300 毫瓦**光源现在可以替代三颗 100 毫瓦激光，减少激光、透镜和隔离器，把组装链简化约三分之二。视频里提到“包括一流激光厂商在内的多家客户已在接触”——这里的激光厂商是作为 Blazar 的接触对象，没有被点名为供货商，**不能写成 Sivers**。

对光互连要分两层。高功率连续波激光短缺，CEO 自己也承认：功率是普通模块激光的数倍，芯片更大更难做；波长如果写在磷化铟里，又要功率又要波长精度，良率会掉。但 Blazar 若做成，走的是另一条路：不需要高规格、波长锁定的高功率 DFB 阵列，而需要简单增益芯片。这是潜在的架构替代，不是谁已经拿到订单。即便仍走传统外置光源，300 毫瓦替代 3 颗 100 毫瓦，也是同一类机制：功率上去，颗数下来。和英伟达说 CPO 比可插拔少用约四倍激光是同一逻辑，部署增加不能按 1:1 换算成激光颗数。
