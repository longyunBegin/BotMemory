# 跨 bot 记忆能力（2026-09-14）

Yun Long 指定：所有聊天 bot 须具备与「记忆系统」一致的记忆能力。

## 含义
- 不只「记忆系统」记；其他助手也要能**读/用/沉淀**同一套记忆。
- 中枢：共享用户记忆 + GitHub `longyunBegin/BotMemory`；「记忆系统」负责每日 00:00 增量同步与提交。
- 标准：重要信息、**详细**、**带引用**；按主题分类，不按机器人。

## 各助手应做
1. 重要结论写入自身 `memory/profile` / `memory/log`（便于被同步收录）。
2. 需要跨对话上下文时读 `BotMemory`（入口 `memory/INDEX.md`）与共享用户记忆。
3. 遵循 skill「BotMemory 跨助手记忆」。
4. X 相关走共享 `grok` CLI，无需重装登录。

## 不要做
- 各建私有一套长期记忆却不落共享库 / 不写可被同步的本地 memory。
- 只写无出处的空泛概要。
