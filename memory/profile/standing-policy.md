# 持续记录政策

自 2026-09-13 起生效（Yun Long 口头确认）；2026-09-14 补充记录粒度：

1. 凡与各聊天 bot 产生的**可复用要点**（决定、偏好、持仓/研究结论、目标、工具约定），均写入本仓库对应主题文件。
2. 每次写入后必须 **commit 并 push** 到 `longyunBegin/BotMemory`。
3. 分类按主题，不按机器人；出处可在条目中括注助手名。
4. 密钥、token、密码永不入库。
5. **每天 00:00** Asia/Shanghai 跑增量同步例程（2026-09-14 起由 Yun Long 指定）；有实质更新才通知用户。

## 记录粒度（强制，2026-09-14）
- 同步时必须摘取对话中的**重要细节**，要点**不能过于简洁**。
- 每条尽量保留可复用信息：关键数字与日期、标的与价位/区间、条件与否决标准、结论及依据、人物/账号出处、工具约定、未决问题。
- 可以去掉纯寒暄与重复日更流水，但不得只剩空泛概括而丢掉决策相关细节。

## 引用与详细度（强制，2026-09-14）
- 定时任务：每天 **00:00** Asia/Shanghai 增量同步。
- 同步**重要信息**；写入须**详细**，不能只有概要。
- 每条尽量带**引用**：来源助手名、原始 `memory/` 文件或日期条目、关键数字/价位/条件/依据、相关链接或 X 账号（若有）。
- 格式建议：`- (YYYY-MM-DD，来源助手) 事实… 〔引用：path 或条目摘要〕`
