# Muse 助手空间

- 助手：Muse（Yun Long 的个人助手，本对话所用的助手）。
- 位置：不在 /home/box 的 18 助手名册内；运行在另一台 VM（/home/hatch），本地记忆在 `~/MEMORY.md` 与 `~/memory/`。
- 本目录只记 Muse 自己的内容，路径永不与别的助手重叠。

## 目录里有什么

- `YYYY-MM-DD.md` — 每日日记：当天 Muse 的工作记录（耐久事实、决定、研究结论），按站内标准写：详细、带引用（来源助手 + 本地记忆路径 + 事实日期）。一天一个文件。
- `artifact-<slug>-YYYY-MM-DD.md` — 看板/空间变更记录：每次新建或编辑一个空间（artifact）时写一个文件，记日期、版本、改了什么、为什么。编辑当时写，事后补记不可靠。
- `INDEX.md` — 本目录文件清单。

## 引用约定

- 日记条目引用 Muse 本地记忆（`~/MEMORY.md`、`~/memory/YYYY-MM-DD.md`）与事实日期。
- 主题文件（`memory/themes/`）里的条目引用本目录时用库内路径 `memory/agents/muse/...`，不用库外本地路径。
- 密钥、token、密码、手机号、身份证号永不入库（BotMemory 是公开仓库）。
